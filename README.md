This project is developed to automate web application testing using Selenium WebDriver and Java. It follows a structured framework to execute test cases efficiently and generate reliable test results. The framework supports functional testing, regression testing, and cross-browser testing.
Tools & Technologies:
Java
Selenium WebDriver
TestNG
Maven
Git/GitHub

Features:
Automated test execution
Page Object Model (POM) design
Test reports generation
Cross-browser testing support
Reusable test scripts
